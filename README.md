# 탐구의 궤적 · 합격·불합격 생기부 탐구 사례집

학교생활기록부 PDF를 올리면 세특·창체를 **탐구 활동 매트릭스**로 펼치고, 지원 대학·전형·모집단위·결과와 **면접 대비 노트**를 함께 담은 A4 가로 PDF 자료집을 만듭니다. 후배 탐구 상담과 학생부 기반 면접 준비에 씁니다.

- 2015 개정(9등급)·2022 개정(5등급) 학생부 자동 구분
- 교과 매트릭스: 등급·성취도·성취도 분포·수강자 수·평균·표준편차 + 탐구 주제·핵심 문장·탐구방법(근거 낱말 밑줄)·독서
- 창체 매트릭스: 자율·자치 / 동아리 / 진로 / 봉사
- PDF 안에서 링크로 이동: 오른쪽 색인 탭, 목차, 매트릭스 ↔ 원문 왕복 링크
- 대학 → 전형 → 모집단위 연결 목록(192개 대학) + 직접 입력

## 개인정보

학생부 PDF는 **이 페이지를 연 컴퓨터의 브라우저 안에서만** 읽고 처리합니다. 서버로 올라가거나 저장되지 않으며, 앱에는 외부로 데이터를 보내는 기능이 없습니다. 이름·주민등록번호·주소·학교명은 읽는 즉시 지웁니다.

**이 저장소에는 학생부 PDF, 저장 파일(.json), 만든 자료집을 절대 올리지 마세요.** 공개 저장소는 누구나 볼 수 있습니다.
